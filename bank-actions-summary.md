# Bank Account Opening Actions

## Essential Actions Required

### 1. Governance Decisions

- [ ] **Choose signing rules** (single vs dual signatory)
- [ ] **Appoint account signatories** (minimum: Chair, Treasurer, Secretary)
- [ ] **Set online banking access levels** (full vs view-only)
- [ ] **Decide on debit card requirements** and spending limits

### 2. Documentation Preparation

- [ ] **Constitution** - finalise and approve
- [ ] **Fundraising policies** - complete document
- [ ] **Financial procedures** - draft management processes
- [ ] **Meeting minutes** - record governance decisions
- [ ] **Officer list** - current committee members with roles

### 3. Legal and Compliance

- [ ] **Public liability insurance** - obtain certificate
- [ ] **Charity registration** - submit application (if pursuing charitable status)
- [ ] **Data protection registration** - if handling personal data

### 4. Financial Planning

- [ ] **12-month financial projections** - draft realistic forecasts
- [ ] **Business plan** - outline fundraising activities and goals
- [ ] **Initial funding source** - document how account will be funded

### 5. Identity Documentation

- [ ] **Photo ID** - collect from all signatories (passport/driving licence)
- [ ] **Proof of address** - recent utility bills/council tax (within 3 months)
- [ ] **Personal bank statements** - if requested by bank

### 6. Bank Application Process

- [ ] **Choose bank** and account type
- [ ] **Complete application forms** in advance
- [ ] **Book appointment** with all required signatories
- [ ] **Prepare initial deposit** to activate account

### 7. Post-Opening Setup

- [ ] **Configure online banking** access for designated users
- [ ] **Order cheque books** and debit cards as required
- [ ] **Set up direct debits** for regular payments (insurance, etc.)

---

**Priority Actions:** Focus on items 1-4 first, as these form the foundation
for the bank application.
