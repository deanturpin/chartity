**Decision Required:** Choose one option below

## Bank Appointment Preparation

### Before the Appointment

- [ ] **Complete application forms** in advance
- [ ] **Gather all documentation** in organised folder
- [ ] **Prepare questions** about account features and fees
- [ ] **Confirm attendees** - bring required signatories
- [ ] **Book appointment** at convenient time for all parties

### During the Appointment

- [ ] **Present documentation** systematically
- [ ] **Ask about special rates** for charitable organisations
- [ ] **Clarify fees and charges** structure
- [ ] **Understand online banking** setup process
- [ ] **Confirm timeline** for account activation

### After the Appointment

- [ ] **Complete any outstanding** documentation
- [ ] **Set up online banking** access
- [ ] **Order cheque books** and cards as needed
- [ ] **Make initial deposit** to activate account
- [ ] **Update constitution** with bank details if required
